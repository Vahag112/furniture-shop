🪑 Furniture Shop

A full-stack e-commerce web application for browsing furniture, managing shopping carts, and handling user accounts. The project features a responsive interface and a REST API built with modern web technologies.

✨ Features
Authentication & Authorization — User registration, login, logout, and JWT-based authentication.
Product Catalog — Browse furniture products and view detailed product information.
Category Filtering — Filter products by category.
Shopping Cart — Add products, update quantities, and remove items.
User Profile — Manage user information and profile avatar.
Admin Panel — Manage products and view users' shopping activity.
Product Management — Create, edit, and delete products.
Responsive Design — User-friendly interface for different screen sizes.
REST API — Backend API for handling users, products, categories, and shopping cart operations.

📂 Project Structure

The application consists of two main parts:

Frontend — The user interface built with Next.js and React.
Backend — A REST API built with NestJS, Prisma, and PostgreSQL.
